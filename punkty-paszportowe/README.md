# Punkty paszportowe w Polsce

Pliki: `punkty-paszportowe.json`

**Źródło:** Strony urzędów wojewódzkich i gov.pl (stan w polu `stan`).

**Format:** id, wojewodztwo, miasto, nazwa, adres, kod, telefon, email, godziny, rezerwacja. JSON, UTF-8.

**Przeglądaj z mapą i wyszukiwarką:** [cityon.pl/paszport](https://cityon.pl/paszport)
