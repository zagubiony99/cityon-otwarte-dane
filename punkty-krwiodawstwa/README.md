# Centra i stałe punkty krwiodawstwa

Pliki: `punkty-krwiodawstwa.json`

**Źródło:** gov.pl/web/nck i strony regionalnych centrów krwiodawstwa; punkty adresowe z PRG (GUGiK). Stan w polu `stan`.

**Format:** `centra` (RCKiK, CKiK MSWiA, WCKiK) i `punkty` (stałe punkty poboru) z adresami. JSON, UTF-8.

**Przeglądaj z mapą i wyszukiwarką:** [cityon.pl/krwiodawstwo](https://cityon.pl/krwiodawstwo)
