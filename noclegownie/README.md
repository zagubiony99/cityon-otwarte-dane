# Noclegownie, schroniska i ogrzewalnie dla osób w kryzysie bezdomności

Pliki: `noclegownie.csv`

**Źródło:** Wykazy placówek prowadzone przez 16 urzędów wojewódzkich (art. 48a ustawy o pomocy społecznej). Adres źródła i data stanu w kolumnach `zrodlo_url` i `stan_na`.

**Format:** wojewodztwo; rodzaj (noclegownia/schronisko/schronisko z usługami opiekuńczymi/ogrzewalnia); nazwa; prowadzacy; ulica; kod; miejscowosc; telefon; miejsc; dla (kobiety/mężczyźni/mieszane); zrodlo_url; stan_na. Separator `;`, UTF-8.
