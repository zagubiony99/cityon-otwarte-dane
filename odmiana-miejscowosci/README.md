# Odmiana nazw polskich miejscowości przez przypadki

Pliki: `odmiana-miejscowosci.json, odmiana-miejscowosci.csv`

**Źródło:** Opracowanie własne CityOn (sprawdzone ręcznie dla miast używanych w serwisie).

**Format:** slug → mianownik, dopełniacz, miejscownik, biernik, narzędnik (np. „w Krakowie”, „z Bydgoszczy”). Przydatne do generowania naturalnych tekstów.
