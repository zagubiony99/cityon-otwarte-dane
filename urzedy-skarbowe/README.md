# Urzędy skarbowe i ich właściwość miejscowa

Pliki: `urzedy-skarbowe-wlasciwosc.json`

**Źródło:** Rozporządzenie w sprawie terytorialnego zasięgu działania organów KAS (Dz.U. 2022 poz. 361 ze zm.) oraz dane teleadresowe KAS z dane.gov.pl (CC0).

**Format:** Lista urzędów z obszarami właściwości (gmina/miasto/dzielnica, powiat). JSON, UTF-8.

**Przeglądaj z mapą i wyszukiwarką:** [cityon.pl/urzad-skarbowy](https://cityon.pl/urzad-skarbowy)
