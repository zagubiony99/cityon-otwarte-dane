# Domy pomocy dla osób starszych z rejestrów wojewodów

Pliki: `domy-seniora.csv`

**Źródło:** Rejestry placówek zapewniających całodobową opiekę (16 urzędów wojewódzkich). Adres źródła i data stanu w kolumnach `zrodlo_url` i `stan_na`.

**Format:** wojewodztwo; nazwa; prowadzacy; ulica; kod; miejscowosc; telefon; www; miejsc; dla; forma; zrodlo_url; stan_na. Separator `;`, UTF-8.

**Przeglądaj z mapą i wyszukiwarką:** [cityon.pl/domy-seniora](https://cityon.pl/domy-seniora)
